## Agent skills

### Issue tracker

Issues and specs live as Markdown files under `.scratch/` in this repo. See `docs/agents/issue-tracker.md`.

### Triage labels

Default triage role names are used as `Status:` values. See `docs/agents/triage-labels.md`.

### Checks

Run `./scripts/check` before finishing a ticket. Review standards live in `CODING_STANDARDS.md`.

### Ticket completion

Run the two-axis `code-review` skill before setting `Status: done`. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: read `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
